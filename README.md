## About

I have been writing for the web professionally since 2006. I started in the Flash and early PHP era, moved with the stack through every generation since, and today I build reactive frontends on Vue 3 and the PHP and Node.js backends behind them.

I like products that are complete: a clean API, an interface that feels fast, a bot or a Mini App where the audience already lives, and a deployment that does not wake anyone up at night. Most of my work is client and platform code under NDA, so this profile is quieter than the commit history behind it.

---

## What I do

- **Frontend**: Vue 3 with the Composition API, component systems, state and routing, performance-minded UI
- **Backend**: PHP and Node.js services, RESTful API design and integration, SQL schema design and query tuning
- **Telegram**: bots and Telegram Mini Apps (TMA), from the bot logic to the payments and the WebApp UI
- **Full cycle**: requirements, architecture, implementation, deployment, long-term support
